=====================================================================
  EJEMPLO DE USO EN ARCHIVO DE TIENDA (Data\Shop\*.txt)
=====================================================================

  Para agregar un objeto a una tienda, se escribe una línea por objeto:

    14,003  0  1  0  0  0  0  //Large Healing Potion
    14,013  0  1  0  0  0  0  //Jewel of Bless
    00,016  0  1  0  0  0  0  //Sword of Destruction
    06,008  0  1  0  0  0  0  //Tower Shield
    07,001  0  1  0  0  0  0  //Dragon Helm
    15,007  0  1  0  0  0  0  //Twister Scroll

  Columnas:
    ItemIndex   = "Sección,Índice" (ej. 14,003)
    ItemLevel   = Nivel (0-13)
    Durability  = Durabilidad (1=default, 255=infinito)
    SkillSwitch = 1=con habilidad
    LuckSwitch  = 1=con luck
    AddOpt      = Opciones adicionales (0-7)
    ExeOpt      = Opción excelente (0=ninguna, bitmask 1-63)

  IMPORTANTE: La línea debe terminar con "end" (sin comillas)
