-----------------------------------------------------------------------------
  FORMATO DEL ARCHIVO DE TIENDA (ShopManager.txt)
-----------------------------------------------------------------------------

  NPCIndex  MapNumber  LocationX  LocationY  Direction  AL0..AL3  GMLevel  "ShopPath"

  Ejemplo:
    230        0         062         130         3         1 1 1 1    *     "230 - Wandering Merchant Alex"

  Columnas:
    NPCIndex  = Índice del NPC en MonsterList.txt (230-255)
    MapNumber = Código del mapa (0=Lorencia, 2=Devias, 3=Noria, etc.)
    LocationX = Coordenada X en el mapa
    LocationY = Coordenada Y en el mapa
    Direction = Dirección que mira (0-7)
    AL0..AL3  = Acceso por level/class (1=todos)
    GMLevel   = Nivel de GM mínimo (*=todos)
    ShopPath  = Nombre del archivo en Data\Shop\


-----------------------------------------------------------------------------
  FORMATO DEL ARCHIVO DE INVENTARIO (Data\Shop\*.txt)
-----------------------------------------------------------------------------

  ItemIndex  ItemLevel  Durability  SkillSwitch  LuckSwitch  AddOpt  ExeOpt  //Comentario

  Ejemplo:
    14,000     0           1          0            0          0        0      //Apple

  Columnas:
    ItemIndex   = "Sección,Índice" del Item.txt (ej. 14,000 = Apple)
    ItemLevel   = Nivel/upgrade del item (0-13)
    Durability  = Durabilidad (0=default, 255=infinito para ammo)
    SkillSwitch = 0/1 - Habilidad activada
    LuckSwitch  = 0/1 - Luck activado
    AddOpt      = Opciones adicionales (0-7)
    ExeOpt      = Opciones excelentes (bitmask 0-63)
