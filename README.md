# YukiMu Online 0.97.11 — Cliente EX097 KOR + Launcher

Cliente Mu Online 97K con launcher KrisbelLauncher integrado.

## Instalacion
1. Descargar todo el repositorio
2. Ejecutar `Launcher.exe`
3. El launcher descargara automaticamente las actualizaciones y abrira `main.exe`
